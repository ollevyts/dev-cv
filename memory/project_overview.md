Next.js 16 App Router portfolio for Oleksandr Levytskyi. Feature-Sliced Design (FSD) architecture under `src/`. Key tech: Tailwind CSS v4, Zustand v5, Framer Motion, Recharts, Lucide React, TypeScript strict.

**Why:** Personal portfolio showcasing front-end engineering skills.
**How to apply:** Follow FSD layers (shared → features → widgets → app). No tailwind.config.js — Tailwind configured in CSS via `@theme` and `@custom-variant`.
